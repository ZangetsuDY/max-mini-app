Роли и права пользователей

Системные роли защищены. Пользовательские роли можно создавать с любым набором зарегистрированных панелей.

АВАРИЙНЫЕ ОТКЛЮЧЕНИЯ · СК-11 OMS

Настройка подразделений активных отключений

Для каждого подразделения укажите одну или несколько строк/ролей из сводок СК-11 OMS. Одна структура используется одновременно для аварийных и плановых отключений, которые приходят из разных чатов MAX.

ДИСПЕТЧЕРСКИЙ МОНИТОРИНГ

Настройка РЭС / районов и источников

Управляйте структурой подразделений и РЭС / районов, строками заявок СК-11 и привязкой подразделений и ролей активных отключений.

ИСТОЧНИКИ НАРЯДОВ / ДОПУСКОВ

Настройка НДР для РЭС / районов

Для каждого РЭС / района укажите строки из сообщения «СК-11 • Наряды / допуски». Если строк несколько, в панели диспетчера сначала показывается их общая сумма, а затем можно открыть каждую запись отдельно.
