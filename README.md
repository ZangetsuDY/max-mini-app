# MAX Mini App — ВЭС с авторизацией

В этой версии добавлена отдельная авторизация перед интерфейсом отключений.

## Что происходит

1. Пользователь открывает Mini App внутри MAX.
2. Появляется плавный экран `Авторизуйтесь`.
3. Пользователь вводит логин и пароль.
4. Backend:
   - проверяет подпись запуска MAX;
   - проверяет логин и PBKDF2-хэш пароля;
   - создаёт HttpOnly/Secure cookie-сессию на 8 часов.
5. Только после этого открывается интерфейс отключений.
6. В верхней панели отображается:
   `Добрый день, ФИО`.

Регистрации нет. Пользователей создаёт только администратор вручную.

---

## 1. Сертификат MAX

Оставьте ваш существующий файл:

`certs/Russian_Trusted_Root_CA.cer`

Его не нужно устанавливать в Windows.

---

## 2. Создание пользователя

На компьютере должен быть установлен Node.js.

Откройте терминал в папке проекта и выполните:

```bash
node scripts/make-user.mjs ivanov "Иванов Иван Иванович" "СложныйПароль123!"
```

Скрипт НЕ сохраняет пароль.

Он выведет объект примерно такого вида:

```json
{
  "username": "ivanov",
  "fullName": "Иванов Иван Иванович",
  "salt": "...",
  "passwordHash": "...",
  "iterations": 210000
}
```

---

## 3. APP_USERS_JSON в Vercel

Vercel -> Project -> Settings -> Environment Variables

Создайте:

`APP_USERS_JSON`

Для одного пользователя значение выглядит так:

```json
[{"username":"ivanov","fullName":"Иванов Иван Иванович","salt":"...","passwordHash":"...","iterations":210000}]
```

Для нескольких:

```json
[
  {"username":"ivanov","fullName":"Иванов Иван Иванович","salt":"...","passwordHash":"...","iterations":210000},
  {"username":"petrov","fullName":"Петров Пётр Петрович","salt":"...","passwordHash":"...","iterations":210000}
]
```

В Vercel удобнее вставлять JSON одной строкой.

---

## 4. AUTH_SECRET

Создайте ещё одну Environment Variable:

`AUTH_SECRET`

Значение — длинная случайная строка, минимум около 40 символов.

Пример формата:

`cH4nge-Th1s-To-A-Very-Long-Random-Secret-2026-x7G2`

Не используйте этот пример буквально.

---

## 5. Уже существующие переменные

Оставьте:

- `MAX_BOT_TOKEN`
- `VES_CHAT_ID`
- `MAX_HISTORY_PAGES` (не обязательно)
- `MAX_LOOKBACK_DAYS` (не обязательно)

---

## 6. После изменения Environment Variables

Сделайте новый Deployment / Redeploy в Vercel.

---

## Добавление нового сотрудника

1. Запустите `make-user.mjs` с новым логином, ФИО и паролем.
2. Скопируйте новый объект.
3. Добавьте его в массив `APP_USERS_JSON`.
4. Сохраните Environment Variable.
5. Redeploy.

Удаление пользователя — просто удалить его объект из `APP_USERS_JSON` и Redeploy.

---

## Безопасность

- пароль не хранится в GitHub;
- пароль не передаётся в `app.js`;
- в Vercel хранится только соль и PBKDF2-хэш;
- сессия хранится в `HttpOnly + Secure + SameSite=Strict` cookie;
- `/api/ves` проверяет и внутреннюю авторизацию, и подпись запуска MAX;
- токен MAX остаётся только на backend.
