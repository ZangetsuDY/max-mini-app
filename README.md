# MAX Mini App — ВЭС

Рабочая версия мини-приложения с чтением сообщений из чата MAX.

## Архитектура

MAX Mini App -> `/api/ves` -> MAX Bot API -> чат ВЭС

Токен бота и chat_id НЕ находятся в браузере.

## Переменные Vercel

В Vercel откройте:

Settings -> Environment Variables

Добавьте:

- `MAX_BOT_TOKEN` — токен вашего бота MAX
- `VES_CHAT_ID` — ID чата ВЭС
- `MAX_HISTORY_PAGES` — необязательно, по умолчанию 5
- `MAX_LOOKBACK_DAYS` — необязательно, по умолчанию 7

После изменения Environment Variables сделайте Redeploy.

## Требования MAX

Бот должен иметь доступ к чату. Для GET /messages в групповом чате бот должен быть администратором.

## Логика

Сообщения типа:

`Аварийное отключение фидера 6-20 кВ`

парсятся по полям:

- Объект
- Запись
- Диспетчер
- Должность
- Время события
- Время добавления

Если запись содержит:

- `отключился`
- `отключен`
- `отключена`
- `отключено`

объект становится активным отключением.

Если более новое сообщение того же объекта содержит:

- `включил`
- `включили`
- `включен`
- `включена`
- `включено`
- `РПВ успешно`

объект удаляется из списка активных отключений.

## Безопасность

Клиент передаёт `window.WebApp.initData` в заголовке `X-Max-Init-Data`.
Backend проверяет подпись по алгоритму MAX и отклоняет запросы,
которые были сделаны не из валидной сессии мини-приложения.

В обычном браузере реальные данные не загружаются.


## Важно: сертификат Минцифры для API MAX

С 19 июля 2026 `platform-api2.max.ru` требует доверия к сертификату Минцифры.

Скачайте официальный корневой сертификат с:

https://www.gosuslugi.ru/crt

и положите его в:

- `certs/Russian_Trusted_Root_CA.cer`

Устанавливать сертификат в Windows для работы Vercel не требуется.
После этого Commit -> Push -> дождитесь нового Deployment Vercel.
