## Оперативная карта региона
В руководительском мониторинге добавлена схематически упрощённая карта Санкт-Петербурга и муниципальных районов Ленинградской области. Географическая компоновка основана на реальном административном устройстве региона; для интерфейса контуры намеренно упрощены и не предназначены для кадастровых/GIS-задач.

Привязки показателей на карте настраиваются в «Центр управления системой → Настройка регионов карты». Для каждой зоны можно выбрать целые подразделения активных отключений и/или конкретные РЭС / районы / ВВР. Настройка сохраняется в Redis.
